## 作用

这是一款通用型增色提亮 LUT，核心功能：

- 修复原图偏冷、偏青、发灰、色彩寡淡的问题；
- 压低冷色（蓝 / 青）、强化暖色（红 / 绿），让画面色彩更鲜亮饱满；
- 优化全画面明暗层次，暗部保细节、高光防过曝，提升整体通透感；
- 统一画面色彩风格，一键出片，适配实拍原图、Log 素材、日常视频 / 照片。

## 适用场景

### 图片 / 视频素材类型

- 原生发灰、偏冷 / 偏青素材：室内自然光、阴天拍摄、逆光灰片、水下 / 背光画面，一键去灰去冷，恢复色彩活力。

- 人像拍摄（写真、生活照、人像视频、直播片段）：优化人物肤色，去除面部泛青、惨白问题，肤色红润自然，同时提升画面质感。

- 风光 / 户外题材：城市街景、自然风景、绿植花海、湖泊海岸、航拍画面，强化植被、建筑、天空色彩，风光更鲜活。

- 日常纪实 & 自媒体内容：Vlog、探店、生活随拍、短视频、活动花絮，快速提升画面观感，批量统一风格。

- 相机 Log 格式素材：搭配官方 Log 还原 LUT 使用，在灰度 Log 基础上增色提亮，兼顾动态范围与色彩表现。

- 轻度美食、静物拍摄：温和提色，还原物体本身色彩。

### 设备 / 软件适配场景

全平台通用：Photoshop、Premiere、达芬奇、Final Cut、剪映专业、各类相机 / 监视器、运动相机、无人机，适合剪辑师、摄影师、自媒体批量调色。

## 不适用场景

- 原生高饱和 / 浓艳素材：原图本身色彩已经很鲜艳，叠加后会出现色彩溢出、偏色、色块、艳俗感，破坏画面质感。

- 冷色调风格创作：日系冷调、ins 青灰风、赛博朋克、夜景冷光、蓝调氛围片，本 LUT 强压蓝色、强行转暖，会彻底偏离创作风格。

- 复古胶片 / 低饱和质感作品：复古暖棕、电影低饱和、黑白风格、莫兰迪淡色系，该 LUT 会拉高色彩浓度，丢失复古、素雅氛围。

- 纯暗光 / 夜视 / 低照度画面：暗部大量负数会放大画面噪点、颗粒，让杂色变多，画质下降。

- 创意单色 / 限定色调作品：单色系、艺术单色、极简配色创作，全局增色会打乱预设色彩设计。

- 专业商业精修图：高端人像精、产品商业图（要求色彩绝对精准），LUT 属于全局统一调色，无法满足逐色精准校准需求。

## 补充使用小贴士

- 叠加后色彩过艳：在 PS / 剪辑软件中降低图层不透明度 / LUT 强度（60%~80%）即可弱化效果；

- 想要保留部分冷色：叠加后手动微调蓝色通道，小幅回拉蓝调；

- 人像使用：若肤色偏红，可轻微降低红色饱和度。
